# 更新日志

这里记录快贴（KwikPaste）的重要变更。

## 2.0.1 - 2026-10-09

- 新增「更改数据目录」：在「偏好设置 › 数据」中可以把记录、图片和设置迁移到其他文件夹，之后也可以恢复为默认位置。
- 更新窗口现在会显示新版本的更新要点摘要。
- 内存占用进一步降低：关闭的窗口会释放显存，剪贴板窗口隐藏时会丢弃缩略图和已隐藏的预览文本，应用和文件图标按显示尺寸解码，Windows 上读取图标的开销也更小。
- 修复剪贴板窗口打开时，快贴会吞掉未绑定任何面板快捷键的按键的问题；现在直接按 Delete 即可删除选中的记录。
- 修复 Windows 上托盘菜单不跟随系统深色模式的问题。
- 修复 Windows 上剪贴板窗口在编辑激活后 Mica 边框变成纯色的问题。
- 修复 macOS 上部分窗口文字难以辨认、权限按钮没有打开对应隐私面板，以及双击剪贴板窗口顶部边缘会使其缩放的问题。

## 2.0.0 - 2026-10-08

- 快贴 2.0 正式版。整个应用改用 Rust 原生界面重写，不再使用 WebView，内存占用大幅降低、打开更快，界面也换上了新的样式。
- 可以直接覆盖安装在 1.x 上，记录、分组、设置和图片都会继续使用。1.x 不会自动更新到 2.0，请从官网或 GitHub 下载安装。升级后 1.x 无法再打开这份数据，如果之后可能退回 1.x，请先在 1.x 中「导出备份」。
- 新增局域网同步：在「偏好设置 › 同步」中开启后，用 6 位配对码配对同一网络中的设备，复制的文本和图片会实时互通。可以分别选择是否同步文本和图片、设置图片大小上限，也可以按地址手动添加设备。
- 新增「粘贴为纯文本」全局快捷键：不打开剪贴板窗口，把当前剪贴板内容去掉格式后直接粘贴。
- 新增「全屏应用中停用快捷键」和「在这些应用中停用快捷键」：前台是全屏应用（如游戏）或列表中的应用时，快贴的快捷键和鼠标按键唤起交还给该应用。
- 录制快捷键时，如果它已被其他程序占用或与快贴的其他快捷键冲突，会直接提示。
- 置顶和收藏的记录可以在剪贴板窗口中拖动排序。
- 「导出备份」和「导出为文件」合并为一个「导出」对话框。备份可以只包含收藏或指定分组，这种备份导入时只能合并；导入备份时可以选择是否同时导入其中的设置。
- 更新只保留一个渠道，「接收测试版更新」和「接收每日构建更新」选项已移除；Windows 上不起作用的「任务栏图标」选项也已移除。

## 2.0.0-beta.1 - 2026-10-07

- 快贴 2.0 的第一个测试版。整个应用改用 Rust 原生界面重写，不再使用 WebView，内存占用更低、打开更快。
- 可以直接覆盖安装在 1.x 上，记录、设置和图片会继续使用。
- 测试版可能还有问题，遇到问题欢迎反馈。

## 1.4.0 - 2026-10-02

- 新增「导出为文件」：在「偏好设置 › 数据 › 备份迁移」中把记录导出为 Excel 或 Markdown，方便阅读、整理和分享。可以只导出收藏或指定分组，合并成一个文件或按分组拆分；敏感内容默认不导出。导出的文件不加密，也不能用来恢复数据，完整备份请继续使用「导出备份」。
- 新增应用内公告：快贴有重要通知（例如新版本发布）时，会在检查更新时以系统对话框告诉你，每天最多一次。点「不再提醒」后这条公告不再出现；关闭「自动检查更新」后，启动时不再获取公告。
- 新装的快贴默认关闭「空格键预览」，「文本预览方式」默认为「选词」。已有的设置保持不变。
- 修复一次复制偶尔生成两条相同记录的问题。
- 修复 Windows 中剪贴板窗口有时被其他置顶窗口挡住的问题。

## 1.3.8 - 2026-09-29

- 新增多选：点击剪贴板窗口底部的「多选」按钮，或在记录的右键菜单中选择「多选」，即可一次选中多条记录并删除。点击选择，按住 Shift 连选，按 Ctrl+A（macOS 为 ⌘A）全选。收藏和置顶记录仍按删除保护设置处理。
- 新增列表显示设置，位于「偏好设置 › 外观」：「列表风格」可选卡片或无间（记录贴边排列，用分隔线隔开）；「列表密度」可选舒适、标准、紧凑或自定义，选自定义时可以单独调整记录间距、上下内边距，以及是否显示头部行。
- Windows 新增「单击托盘图标打开」：可以选择单击托盘图标时打开剪贴板窗口还是偏好设置。在「偏好设置 › 通用」的「系统托盘图标」下设置，默认仍打开剪贴板窗口。
- 偏好设置界面更简洁：设置项不再带图标，只在需要时显示说明；「数据概览」成为侧栏中的独立页面。
- macOS 现在可以用 Homebrew 安装：`brew install --cask mansandadada/tap/kwikpaste`。
- 修复 Windows 中把文本拖到 WPS 等应用时无法放下的问题。
- 修复 Windows 调大「文本大小」后，偏好设置窗口无法缩小回 960×600 的问题。

## 1.3.7 - 2026-09-28

- 重做「偏好设置 › 数据」中的「自动清理」。记录改为按最后一次使用的时间过期，不再按第一次复制的时间：很早以前复制、至今每天还在粘贴的内容会被保留。即使关闭了「复用时更新记录」，从历史中复制或粘贴也算作使用。
- 新增自定义清理规则。可以给文本、图片、文件、敏感内容、来自某些应用的记录、超过指定大小的记录或只复制过一次的记录单独设置保留时长，从几分钟到永久保留。规则从上到下匹配，没有命中任何规则的记录按「默认保留时长」处理。内置大于 5 MB 的图片、敏感内容等常用规则，一键添加。
- 保存会立即删除记录的清理设置前，会先列出将要清理的条数和原因，确认后才保存。新增「清理状态」，显示最近一次清理的结果，并可「立即清理」。
- 自动清理现在也会保留放入自定义分组和写了备注的记录，与收藏、置顶一样。
- 清理设置修改后立即生效，不必等到下次启动，「自动清理周期」设置随之移除。「最大保留条数」在有新记录时即刻生效，存储上限也不再每分钟扫描一遍数据目录。
- 存储超出上限时，剪贴板窗口底部会给出提示：「仅提醒」模式下超限即提示，「自动清理」模式下在清理也无法回到上限以内时提示。点击提示可直接打开存储设置。
- 清理记录后数据库文件会随之变小。已有数据需在「偏好设置 › 数据」中执行一次「清理缓存」，压缩数据库并开启此功能。
- Windows 新增「鼠标按键唤起」：单击鼠标中键或侧键即可打开或隐藏剪贴板窗口。默认关闭，可在「偏好设置 › 快捷键」中开启。
- 偏好设置重新整理为九个分类，每个分类的全部设置在同一页中滚动查看，顶部可跳转到各分组。
- 修复在备注、分组、确认弹窗、下拉菜单或搜索框中按键时，按键同时作用到列表的问题，例如按 Enter 粘贴了选中记录、按 Esc 隐藏了窗口。
- 修复 Windows 中在搜索框里按 Ctrl+V 等 Ctrl 组合键时，按键落到之前所在应用的问题，以及方向键会离开搜索框的问题。
- 修复 Windows 中打开备注和分组弹窗时，输入框没有立即获得焦点的问题。

## 1.3.6 - 2026-09-26

- 新增「数据概览」：在「偏好设置 › 数据」中查看存储空间的构成、记录总数、每日新增、内容构成和来源应用，还能一次清理某类内容或某个应用的全部记录，收藏和置顶会保留。点击左下角的存储占用可直接打开。
- 修复 Windows 多显示器且开启了显示缩放时，剪贴板窗口弹到主屏、而不是光标所在屏幕的问题。
- 修复在 Windows 中调大「文本大小」后，剪贴板、偏好设置、更新、右键菜单、预览和新手引导窗口内容被裁切的问题。这些窗口现在会跟着变大，新手引导中放不下的步骤可以滚动查看。
- 修复使用云母或亚克力窗口材质时，置顶记录显示成一块不透明色块的问题。
- 修复同时开启「管理员权限启动」和「开机启动」时，每次登录都弹出用户账户控制确认的问题。笔记本用电池供电时以管理员权限启动失败的问题也一并修复。
- 修复导入备份后，快捷键、托盘图标和开机启动仍按导入前的设置生效的问题。
- 修复偏好设置中下拉选项显示不全的问题，例如快速粘贴的修饰键选项只显示「Ctr...」。

## 1.3.5 - 2026-09-25

- 修复从浏览器等应用复制的图片，每粘贴一次就多出一条重复记录的问题。粘贴大图也更快了，两三百万像素的图片耗时降到原来的四成左右。
- 修复剪贴板窗口开着时，新复制的图片一直显示灰色占位、或显示成上一张图片的问题。
- 在剪贴板列表中悬停、选中和滚动时，只重绘有变化的卡片，不再重绘所有可见卡片。
- 翻页浏览历史、分类标签、自定义分组和历史清理改为走数据库索引，记录再多也不会变慢。更新后首次启动会建一次索引，2 万条记录约需 1 秒。
- 复制时不再每次都提取来源应用的图标，每个应用只读取一次。
- 「应用信息」新增「官方网站」链接，GitHub 仓库移到单独的「开源地址」。

## 1.3.2 - 2026-09-24

- 新增「快速粘贴」：按住修饰键再按数字，不用打开剪贴板窗口就能直接粘贴。1–9 粘贴第 1–9 条，0 粘贴第 10 条，顺序与「全部」列表一致。默认关闭，可在「偏好设置 › 快捷键」中开启，修饰键默认是 Ctrl+Shift，也可以改。
- 文本记录下方会列出其中提取到的编号、型号、数字和链接，点一下只粘贴这一段。默认开启，可在「提取快捷信息」中关闭。
- 新增「拆词」：把一条文本拆成词，挑出需要的几个，只粘贴这几个。
- 指针移到悬停预览上时预览不再消失；预览中的文本可以切换为按词显示，直接在预览里点选粘贴。
- 全新安装默认开启悬停预览，已有安装保留原来的设置。
- 全新安装打开剪贴板窗口时默认选中「全部」，已有安装保留原来的设置。
- 打开偏好设置时会自动隐藏剪贴板窗口。
- 新增 Windows 便携版：解压即用，数据保存在程序旁的 `data` 文件夹里，应用内更新会原地替换便携版。
- Windows 安装包从 7.6 MB 缩小到 4.2 MB。

## 1.3.0 - 2026-09-24

- 新增「存储上限」设置，默认 1 GB，左下角的存储占用以它为满格。超出后默认只提醒；改为「自动清理」后，会从最旧的普通记录删起，直到回到上限以内，收藏和置顶始终保留。
- 「清空记录」从剪贴板窗口的更多操作菜单移到设置的「存储位置」中。
- 托盘菜单精简为「偏好设置」和「退出应用」，托盘提示不再显示版本号。
- 检查更新改为走系统代理，并同时查询所有已开启的渠道；连不上服务器时会超时返回，不再一直卡住。

## 1.2.0 - 2026-09-23

- 启用应用内自动更新。更新包使用快贴自己的密钥签名，安装前会校验；下载走国内 CDN，GitHub 作为备用。
- 自动检查更新默认开启，并默认接收测试版和每日构建。同时开启多个渠道时，会安装其中版本最新的一个。
- 统一各窗口的材质与外观设置：系统支持时使用原生材质，不支持时自动降级。
- 悬停预览改为原生材质的面板窗口。
- 图片缩略图改为按需加载，加载完成前显示同尺寸的占位。
- 悬停预览不再在每一帧重复初始化窗口和加载数据。
- 减少多余的数据库读取和全文索引重写。
- 修复悬停预览面板的位置和透明度问题。
- Windows 与 macOS 上的应用和安装包统一命名为 KwikPaste。
- 移除首次启动时的旧版数据导入步骤。

## 1.1.0 - 2026-09-16

- 确立中文产品名 **快贴**，英文技术名 **KwikPaste**。
- 应用标识改为 `com.fastthree.kwikpaste`。
- 应用、安装包、网页图标和托盘图标统一替换为 KwikPaste K 标识。
- 使用 `.kwikpastebak` 备份包与独立的 `KwikPasteData` 数据目录。
- 在 FastThree 签名和发布基础设施完成前停用继承的自动更新。
- 移除继承的赞赏二维码入口，项目链接改为 `https://paste.fastthree.com`。

更早的上游版本记录可在 [EcoPaste](https://github.com/EcoPasteHub/EcoPaste) 仓库查看；必要的来源与版权声明保留在 README 和 LICENSE 中。
